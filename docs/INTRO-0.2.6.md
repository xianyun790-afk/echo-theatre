1. 门前展示简短前情：二十年前的火灾、林见秋的身份与记忆缺口、匿名信带来的重返。文案来自既有第一幕角色本和旁白，不提前展示第二幕事件或其他人的秘密。
2. 点击「推门，阅读我的剧本」，保留开门镜头，随后弹出旧纸风格角色本。
3. 角色本交代年龄／职业、来意、当前目标和私人记忆。点击「我已了解，开始调查」后才播放原童谣、开放物件调查与主持人输入。角色本按钮固定在底部，正文可独立滚动；可返回门前重读。
4. 底栏「我的剧本」可重看；更多选项中可回看前情、使用演示跳转、重开第一幕。入口明确第一、二幕为单人试玩，第三幕尚未开放。
