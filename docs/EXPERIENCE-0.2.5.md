# 0.2.5 第二幕核心体验调整

日期：2026-10-28。基线：0.2.4。按玩家实际反馈的六项问题修改。

## 1. 正文可见性与停止播放

- 陈述正文直接显示在当前任务顶部，不再藏在“最新记录”的内部滚动区下方。切换角色时阅读区回到顶部，手机自动把正文带入视野。
- 当前阅读角色独立保存；播放结束、停止和刷新都不会自动换到下一人。“停止播放”“播放这段陈述”和“下一位”是独立操作，默认支持纯文字阅读。
- 广播提供独立完整文本面板，阅读确认后再进入核对。

## 2. 共用时间轴

- 每人一行，共用20:10、20:35、20:46、20:50、21:05、21:07列；三处关键节点可点击高亮整列，原始陈述可展开回看。
- 1280×720下六行可同时比对。手机横向滚动，姓名列固定。
- 未陈述者的活动仍隐藏。林见秋只展示玩家实际提交的原文，不用私人角色本预设路线补全位置。21:05/21:07公共锚点只在B01记录后显示。

## 3. 推理提交的回报

- 提交疑问后先显示推理回应，包含相关公开依据、当前缺失的一环、本幕能执行的核对，再由玩家选择修改问题或保留方向走到走廊。
- 针对时间、名册、声音与维护痕迹，以及问题里的具体对象给出不同反馈。只使用已公开材料，明确哪些档案本试玩没有提供，避免暗示反复追问会解锁新证据。
- 回应是基于公开材料的规则反馈，不把玩家的推测判成事实，不新增凶手、时间或医学结论。反馈快照随存档保存；结束记录展示反馈，JSON导出包含结构化依据与缺口。

## 4. 场景热点

- 名册、广播台、七号房门轴增加跟随实际三维物件投影的标签热点，支持鼠标、触屏和键盘；桌面物件区域也可直接点击名册。
- 名册从场景进入证据查看与记录。广播台可查看现场近景，六人陈述齐后可播放录音。门轴在程野公开B06后进入证据；此前只查看门外，不提前泄露他的观察。

## 5. 事实与提示分开

- 角色陈述保留实际活动、亲眼或亲耳所及及观察空缺，移除反复替玩家下结论的旁注。推理提醒放入玩家主动展开的提示。
- 证据正文与“需要推理提示？”分开。时间线的资料差异、比对提醒和原始陈述也放在可选区域。
- 同步固定朗读，更新8条配音缓存：名册、陈述开场、结尾、湿鞋、林见秋/周叙/程野/唐棠陈述。总缓存路径仍为82，角色音色映射保留；旧缓存文件保留以便回退。
- 主持人只建议本幕可以完成的核对；未提供的登记人、制作人、维护时间直接说明缺失。实测曾出现建议比对未提供的笔迹细节，已收紧提示，禁止笔迹或字形比对及不存在的档案入口；引用录音要求逐句照录。

## 6. 试玩范围与阶段成果

- 第二幕开场及恢复入口的场景标题下说明：本次试玩含第一、二幕，止于七号房门外，第三幕未开放。
- 结束时明确展示现场记录、六人陈述、广播与玩家自己的查证方向，保留推理回应；不再用持续进入下一幕的文案作当前目标。结尾朗读也同步调整。
