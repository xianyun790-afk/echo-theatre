# 0.2.7 · 集中推理语音输入

日期：2026-10-28。基于0.2.6。

## 修复范围

第一幕「集中推理」的林见秋公开陈述和相互质询此前只有文字框，未接入搜证阶段已有的语音能力。新增「语音输入」入口，复用本机中文识别服务，将话语填入可编辑草稿，再由玩家点击「公开我的陈述」或「提出质询」。其他角色仍为预设发言。

- 点击麦克风暂停当前配音，暂时抑制背景音乐。
- 说完停顿后自动识别，也可点击「说完了，转成文字」手动结束。录音期间可取消；识别等待期间也能取消。
- 识别文字追加到已有草稿；保留400字陈述、300字质询上限，截断时明确提示。
- 不自动公开草稿或提交质询；采集／识别期间禁用提交，文字可随时修改。输入文字会取消当前识别，迟到结果不覆盖修改。
- 切换对象、打开资料、离开集中推理、组件卸载时关闭麦克风和取消待处理识别。识别失败保留原文字，允许重试或直接提交文字。
- 调整输入区域布局，避免桌面证据浮钮遮住输入框。引用证据仍可通过选项和底栏查看。

## 技术与存档

新增SpeechDraftInput组件供两处输入复用；LocalSpeechSession增加finish()手动完成录音，stop()仍为取消。集中推理仍保存既有CouncilDraft，无需修改存档格式，已输入草稿刷新后可恢复。

此处是本机Vosk中文转写；音频仅送本机/api/transcribe，不连接实时主持人、不替玩家生成观点。搜证阶段和第二幕的NIA实时主持人保持原实现。没有更改固定配音、音色或缓存，82条manifest与0.2.6相同。
