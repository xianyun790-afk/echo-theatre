# 第二幕 · 七号房没有人（0.2.0）

制作日期：2026-10-28。依据用户提供的《第七个孩子-线上语音前三幕.zip》，沿用单人试玩、林见秋视角与NIA角色音色。

## 可玩流程

1. 停电与上楼：两段旁白或完整文字阅读。
2. 值班室现场：查看并记录B01停电与声响、B02浸湿的名册。
3. 活动陈述：玩家提交林见秋活动，可选择公开B03；依次听取沈、周、许、程、唐的原稿演示，公开B04/B05/B06。
4. 四句广播文本演绎，完整播放后继续；也可阅读完整文本并明确确认。
5. 时间线、语音或文字讨论、保存查证方向和待追问问题。
6. 梁素琴告知塌方与警方绕行，七号房门缝收束，保存记录与JSON导出。第三幕未开放。

值班室与走廊为新建Three.js场景。名册、广播台、耳机、碎杯、七号房门为本地几何物件。桌面三列布局，手机纵向阅读和操作。

## 剧情与改编

- 死因、准确死亡时间、值班室是否反锁均未定；不补药物、伤口、医学结论、暗道或现案凶手。
- B05与周叙角色本对拍摄站位有“大厅”和“一楼楼梯口”的差异。保留共同事实20:46拍到顾进入值班室，时间线标注来源差异，不据此补造视野、不在场证明或后续进出。
- 第二幕许知音陈述公开不是同一份音轨的判断，不回写第一幕“待比对”记录。
- B03私有，查看自己的剧本不会自动公开；未公开时模型不接收湿鞋观察、私人草稿或笔记。其他五人的完整私人本与第三幕内容未放进前端数据。
- 其他角色按原稿作演示陈述。没有新增多人房间。
- 录音原稿仅有对白文本，新增配音是文本演绎，不声称原始录音或声音身份鉴定。

## 代码与存档

- `src/lib/act-two.ts`：本幕内容、状态结构、存档校验、本地回复。
- `src/components/ActTwo.tsx`：交互与固定音频流程。
- `src/components/ActTwoScene.tsx`、`act-two.css`：场景与自适应布局。
- `config/act-two-public.json`、`scripts/act-two-config.mjs`：专用公开事实与服务端提示。
- 每次GameContext携带 `act:2`，relay选择第二幕事实白名单和三项导航工具；第一幕默认1。
- 第二幕独立 `echo-act-two-v1[-qa-<scope>]`；第一幕 `echo-act-one-v2` schema 3保留。URL使用act=2，qa参数跨幕保留。
- 刷新恢复当前阶段、草稿、陈述、公开线索与追问，不自动续播。
