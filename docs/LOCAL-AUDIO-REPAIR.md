# 本地播放修复（2026-10-21）

目前 config/voices.json 的 cache_only=true：仅读取已生成的配音，不发起云端合成。账户恢复后再单独恢复合成，不能把旧语速缓存误记为新参数的生成结果。

- 已有 MP3 保留在原缓存；播放版本单独存为 mono 32kHz PCM16 WAV。
- 按有效人声帧统一至约 -20dBFS RMS，增益最多六倍，峰值不超过 -3dBFS。动态特别大的片段以峰值约束为准。
- 不裁字、不拉伸、不改音高。原音频前后增加120/80ms静音。
- 人声在调用play前即为正常音量，不做吞字的渐入，也不在自然结束时压掉尾音。字幕提前320ms提示；主动中断仍淡出140ms。
- 背景音乐在人声时降至4%；无旁白时延迟450ms、再用700ms恢复至32%。集中推理和麦克风录音期间暂停背景音乐。
- 开场歌曲仍用用户原文件，保留歌曲的渐入和渐出，与背景音乐互斥。

验证：34项前端测试、17项Python测试、构建通过；38段基础配音及20个集中推理问答角色版本均可从现有缓存播放。网页验证开场童谣结束后 n01-return 为 playing、readyState=4、currentTime=5.24秒；切换调查点时旧段落被移除。原始音色的咬字或口音不能由响度修复改变，需账户恢复后重新生成并试听。
