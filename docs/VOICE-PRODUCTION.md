# 《第七个孩子》第一幕配音清单

本清单仅覆盖当前第一幕《请在熄灯前回家》。这是原创 Demo 的配音清稿。当前按原定角色方向匹配 NIA 的7套音色；旁白和主持人共用晚舟，其他6个角色各用独立音色。38段基础台词与20段按质询对象区分的回应，共58条播放路径。固定台词由 WS1 PostSayIt 按正文生成并缓存在本机；实时主持人使用 WS1 纯 WebSocket PCM 流，沿用同一晚舟音色。

## 使用约定

- 原定旁白音色参考为用户提供的 `minimax-1792584016789.mp3`，项目内副本为 `public/audio/narrator-reference.mp3`。当前从 NIA 音色库选用晚舟；未对参考样本做克隆，样本保留供后续试听比较。
- 音色描述是匹配方向，不能保证达到精确年龄、疲惫或迟疑的表演效果。当前全部使用正常语速1.0，不对声音变调。
- 广播直接播放用户提供的《小朋友》原文件，项目内为 `public/audio/opening-song.mp3`。不生成替代童谣，不另加歌曲界面，不重唱，不推写未经核对的歌词。
- N01–N17 对应当前场景旁白。H、R、Q 对应主持人和角色回应。技术演示标签不读入角色台词。
- 单段单文件，建议按下列文件名导出 MP3 或 WAV；所有台词只读正文，不读编号、角色名、触发说明。旁白不叠雨声、音乐、电流或混响，效果留给网页统一处理。
- 当前歌曲在游戏页面载入时自动尝试播放，推门后继续当前音轨，广播可重播同一首歌。歌曲优先：自然播完后接 N01，已推门则再接 N02；歌曲结束后才推门则单独接 N02。N04 仅用于广播重听结束。N03 在走近广播时播放。N10 用于记录手印后的引导，H06 用于玩家主动询问提示。切换物件、打开弹窗、提问会取消旧链条，不会积压补播。语音先显示字幕，预留约320ms后起声，保留120ms静音头和80ms静音尾，不渐入吞字；歌曲约 1 秒渐入，打断时约 140ms 渐出；背景恢复先留白再用 700ms 渐强。麦克风开启时立即停止外放。
