# 0.2.1 第二幕界面整理与引导

日期：2026-10-28。此版在0.2.0基础上整理第二幕界面，保留原剧情、第一幕和存档schema。

## 界面层级

1. 场景：保留暗色档案气氛和3D场景，章节名缩为一行，自由切换场景默认折叠。
2. 当前任务：一个金色主按钮，提示跟随进度变化。桌面主按钮固定在任务卡底部，长正文单独滚动，输入框与按钮互不遮挡。现场先查看B02名册，再核对B01停电；旧存档已记录的线索自动跳过。
3. 引导：「接下来」给具体操作，顶部六段进度条展示位置，点击打开完整流程。
4. 资料：证据本、时间线、个人剧本集中到底栏。广播全文、历史字幕与辅助核对按需展开；播放时自动展开当前字幕，停止后可继续阅读。
5. 主持人：点击底栏「问主持人」才挂载语音/文字对话，关闭面板卸载会话。按钮、Esc和遮罩均可关闭。
6. 手机：紧凑场景预览、纵向任务卡、底部工具入口；资料面板保持原生dialog焦点约束。
